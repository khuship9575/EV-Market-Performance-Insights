# EV-Market-Performance-Insights
## Project Overview
This project explores electric vehicle data using Tableau to understand manufacturers, vehicle range, battery types, and available sales information.
## Objectives
- Explore EV manufacturers and vehicle counts.
- Compare vehicle range across battery types.
- Analyze sales information where available.
- Present insights through an interactive dashboard.
- ## Tools Used
- Tableau Public / Tableau Desktop
- CSV Dataset
- GitHub
- ## Visualizations
1. Annual EV Sales by Manufacturer
2. EV Range by Battery Type
3. EV Count by Manufacturer
 ## Dashboard
The dashboard combines the visualizations and provides a manufacturer filter for interactive exploration.
## Limitations
Vehicle counts do not necessarily represent sales. Sales conclusions depend on the availability and quality of valid sales data.
